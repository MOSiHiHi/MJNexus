## خلاصهٔ استخراجی (از کپشن)
Permissionها در لینوکس فقط چند عدد مثل 755 و 644 نیستند؛ پشت هرکدام یک ترکیب مشخص از دسترسی Read / Write / Execute برای Owner، Group و Others قرار دارد. اگر این منطق را بفهمی، کار با chmod خیلی ساده‌تر می‌شود و کمتر سراغ دسترسی‌های خطرناکی مثل 777 می‌روی.
