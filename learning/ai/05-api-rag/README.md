# ⭐ ۵. ساختن با API و RAG

نگارش: ۲۰۲۶-۱۰-۱۰ · پیش‌نیاز: [۱](../01-llm-basics/README.md)، [۲](../02-prompting/README.md)، [۴](../04-agents-automation/README.md) · بعدی: ۶ و ۸ (درخت)

## چرا مهم است
وقتی از کد به مدل وصل شوید، هر چیزی را می‌توانید خودکار کنید و مدل را روی **دادهٔ خودتان** کار دهید — مثلاً پرسیدن «کدام صفحه‌های نمایه‌ام آموزش رایگان ریاضی برای مبتدی دارند؟» و گرفتن پاسخ از روی همین ۹۵۰۰ حساب.

## مفاهیم کلیدی
- **صدازدن API:** یک درخواست HTTP با کلید API، مدل، پیام‌ها (سیستمی، کاربر) و تنظیمات (حداکثر توکن، دما). پاسخ: متن + شمار توکن‌ها برای محاسبهٔ هزینه.
- **کلید API:** مثل رمز است؛ هرگز در کد عمومی یا چت نگذارید (در همین پروژه کلید Apify در تنظیمات محیط است، نه در مخزن).
- **embedding:** تبدیل متن به بردار عددی؛ متن‌های هم‌معنا بردارهای نزدیک دارند. پایهٔ جست‌وجوی معنایی (نه فقط کلیدواژه‌ای).
- **RAG (Retrieval-Augmented Generation):**
  1. اسناد را تکه‌تکه (chunk) کنید و embedding هر تکه را ذخیره کنید (پایگاه‌دادهٔ برداری).
  2. با هر سؤال، تکه‌های مرتبط را بازیابی کنید.
  3. آن تکه‌ها را همراه سؤال به مدل بدهید و بخواهید فقط بر پایهٔ آن‌ها و با ارجاع پاسخ دهد.
  → توهم کمتر، دانش به‌روز و خصوصی.
- **خروجی ساخت‌یافته:** خواستن JSON با طرح مشخص و اعتبارسنجی آن در کد؛ لازمهٔ وصل‌کردن مدل به برنامه.
- **ارزیابی (eval):** مجموعه‌ای از سؤال‌ها با پاسخ مورد انتظار؛ هر تغییر در پرامپت یا مدل را با آن می‌سنجید.

## مثال (پایتون، ساده‌شده)
```python
import anthropic  # یا SDK هر ارائه‌دهندهٔ دیگر
client = anthropic.Anthropic()          # کلید از متغیر محیطی خوانده می‌شود
msg = client.messages.create(
    model="claude-sonnet-5-5", max_tokens=300,
    messages=[{"role": "user", "content": "این بیو را در یک خط فارسی خلاصه کن: ..."}])
print(msg.content[0].text, msg.usage)  # متن و شمار توکن‌ها
```

## اشتباه‌های رایج
- گذاشتن کلید API در کد یا مخزن عمومی.
- RAG بدون ارجاع به منبع؛ نمی‌شود فهمید پاسخ از کجا آمده.
- تکه‌های خیلی بزرگ یا خیلی کوچک؛ بازیابی بد → پاسخ بد.
- نداشتن eval؛ «به نظرم بهتر شد» جای سنجش نیست.

## تمرین ۱۰ دقیقه‌ای
فایل `instagram-index/index/profiles.tsv` را در یک ابزار چت که فایل می‌پذیرد بارگذاری کنید و بپرسید: «۵ حسابی که آموزش ریاضی دارند را با دلیل از روی بیو نام ببر.» بعد پاسخ را با خود فایل چک کنید — این یک RAG دستی است. نتیجه را در `resources/` ذخیره کنید.

## سؤال‌های سنجش
- **پلهٔ ۱:** API چیست و چرا کلید API باید محرمانه بماند؟
- **پلهٔ ۲:** embedding چیست و چرا جست‌وجوی معنایی از جست‌وجوی کلیدواژه‌ای بهتر است؟ یک مثال از نمایهٔ خودت بزن.
- **پلهٔ ۳:** یک سامانهٔ RAG روی نمایهٔ دنبال‌شده‌هایت طراحی کن: تکه‌بندی، ذخیره، بازیابی، پرامپت و ارزیابی.
