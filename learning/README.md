# خزانهٔ یادگیری

مسیر یادگیری، تعیین سطح و همهٔ فایل‌های مرتبط — هر فرمتی، برای هر هدفی — در یک جا، به شکلی که هم خودتان و هم ایجنت‌ها (Claude و اجراهای زمان‌بندی‌شده) بتوانند آن را بخوانند، اضافه کنند و نگه دارند.

## ساختار
```
learning/
├── README.md            ← همین راهنما
├── CLAUDE.md            ← قواعد کار ایجنت‌ها با خزانه
├── progress.md          ← کارنامهٔ سطح (فقط از جواب‌های واقعی)
├── glossary.md          ← واژه‌نامهٔ فارسی–انگلیسی
├── inbox/               ← هر فایلی را اینجا بیندازید تا ثبت شود
├── catalog/
│   ├── catalog.jsonl    ← فهرست ماشین‌خوان همهٔ فایل‌ها
│   └── text/            ← متن استخراج‌شده برای جست‌وجو
├── tools/ingest.py      ← افزودن و فهرست‌کردن فایل‌ها
└── ai/                  ← یک حوزه
    ├── tree.md          ← درخت گره‌ها و روش سنجش
    └── 01-llm-basics/   ← یک گره
        ├── README.md    ← ویکی گره + سؤال‌های سنجش + منابع
        └── resources/   ← فایل‌های شما برای این گره
```
حوزه‌های بعدی (بازی‌سازی، ریاضی و …) با همین الگو کنار `ai/` اضافه می‌شوند.

## افزودن فایل
هر نوع فایل پذیرفته می‌شود: متن، Markdown، PDF، Word/Excel/PowerPoint، عکس، صدا، ویدیو، سورس‌کد به هر زبان، نوت‌بوک، آرشیو، و حتی فایل باینری.

```sh
# یک یا چند فایل، برای یک گره و یک هدف
python3 -I learning/tools/ingest.py notes.pdf screenshot.png --node ai/02-prompting --purpose study \
    --tags "few-shot" --source "https://…" --note "خلاصهٔ دوره"

# همهٔ فایل‌های inbox
python3 -I learning/tools/ingest.py --inbox --node ai/05-api-rag --purpose work

# فهرست
python3 -I learning/tools/ingest.py --list --node ai/05-api-rag
```
**هدف‌ها (`--purpose`):** `study` مطالعه · `example` نمونهٔ مطالعه‌شده · `exercise` تمرین · `reference` مرجع · `work` خروجی کار واقعی

**چه اتفاقی می‌افتد:** فایل بدون تغییر در `resources/` گره ذخیره می‌شود (نام با پیشوند هش تا تکراری‌ها شناخته شوند)، یک خط در `catalog.jsonl` ثبت می‌شود، و متن قابل‌جست‌وجو استخراج می‌شود:

| نوع | استخراج |
|---|---|
| متن و سورس‌کد (هر زبان) | متن کامل |
| PDF | متن با `pdftotext` |
| Word / PowerPoint / Excel | متن از XML داخلی |
| عکس | ابعاد؛ و علامت «نیاز به توصیف» تا ایجنتی که تصویر می‌بیند توضیحش را بنویسد |
| سایر باینری‌ها (اجرایی، صدا، ویدیو، آرشیو…) | نگهداری کامل + توصیف نوع فایل؛ پردازش ویژه در صورت نیاز با ابزار مناسب |

بدون خط فرمان هم می‌شود: فایل را در گفت‌وگو با Claude بفرستید و بگویید برای کدام گره و چه هدفی است؛ Claude همین ابزار را اجرا و نتیجه را push می‌کند.

## محدودیت‌ها و حریم خصوصی
- **این مخزن عمومی است.** فایل شخصی یا محرمانه را اینجا نگذارید؛ در Google Drive (یا مخزن خصوصی) نگه دارید و در خزانه فقط یک فایل مرجع با لینک ثبت کنید.
- **حجم:** فایل‌های بالای ۵۰ مگابایت ثبت نمی‌شوند (سقف گیت‌هاب ۱۰۰ مگابایت است). برای فایل‌های بزرگ: Google Drive یا Git LFS (سهمیهٔ محدود).
- هیچ فایلی خودکار حذف نمی‌شود.
