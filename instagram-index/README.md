# نمایهٔ پژوهشی اینستاگرام

هدف: برای هر صفحه‌ای که دنبال می‌کنم، با کمترین زمان بفهمم چیست، چه محتوایی دارد، به چه دردی می‌خورد و به چه منبع بیرونی (سایت، محصول، دانش، پروژه، مکان…) اشاره می‌کند. تمام اجرا در فضای ابری است؛ بدون ورود به حساب شخصی، و صفحه‌های خصوصی رد می‌شوند.

## ساختار

| مسیر | محتوا |
|---|---|
| `input/following.json` | خروجی اینستاگرام؛ ۹۵۰۵ نام کاربری یکتا (اعتبارسنجی ۲۰۲۶-۱۰-۰۶) |
| `tools/probe.py` | آزمون مرحله‌ای پروفایل‌های عمومی (حالت `http` یا `browser`)؛ با دیدن صفحهٔ ورود، چالش یا محدودیت نرخ متوقف می‌شود |
| `pilot/sample-10.txt` | نمونهٔ تصادفی پایلوت (seed=2026) |
| `tools/discover.py` | جمع‌آوری از API رسمی (Business Discovery)؛ قابل ادامه |
| `docs/api-setup.md` | راه‌اندازی API و دستور ادامه در سشن بعد |
| `tools/apify_profiles.py` | **مسیر فعلی:** دریافت پروفایل‌ها از Apify، با سقف هزینه و قابل ادامه |
| `index/profiles.tsv` | **نمایهٔ یکپارچهٔ همهٔ پروفایل‌های دریافت‌شده** به ترتیب رتبه |
| `lists/ranked.tsv` | فهرست رتبه‌بندی‌شده (شناخته‌شده ← ناشناخته)؛ `lists/batch-*.txt` دسته‌ها |
| `pilot/log.md` | گزارش قدم‌به‌قدم آزمون‌ها |

## اجرا

```sh
pip install playwright   # مرورگر از قبل در /opt/pw-browsers/chromium نصب است
python3 -I tools/probe.py http    runs/<id> 30 user1 user2 ...
python3 -I tools/probe.py browser runs/<id> 30 user1 user2 ...
```

نتایج هر اجرا در `runs/<id>/results.jsonl` (یک خط برای هر حساب، با زمان مشاهده) و اسکرین‌شات‌ها در همان پوشه ذخیره می‌شوند.

## وضعیت فعلی

نگاه کنید به `pilot/log.md`.

## اجرای ماهانه (رایگان و آهسته)

هر ماه پس از تمدید اعتبار رایگان Apify:

```sh
cd instagram-index
python3 -I tools/monthly.py --dry-run   # فقط نشان می‌دهد چند حساب در بودجه جا می‌شود
python3 -I tools/monthly.py             # دستهٔ بعدی را می‌گیرد، گزارش و index/profiles.tsv را به‌روز می‌کند
```
