# راه‌اندازی API رسمی اینستاگرام (Business Discovery)

## چه می‌دهد و چه نمی‌دهد
- برای حساب‌های **عمومی تجاری/تولیدکننده**: نام کاربری، نام، بیو، وب‌سایت، تعداد دنبال‌کننده/دنبال‌شونده/پست، آدرس عکس پروفایل، و برای پست‌ها: کپشن، لینک مستقیم، زمان، نوع، تعداد لایک/کامنت.
- حساب‌های **شخصی یا خصوصی** برنمی‌گردند → خودکار «دردسترس‌نبودن» ثبت و رد می‌شوند.
- اسکرین‌شات نمی‌دهد و پست پین‌شده را مشخص نمی‌کند.
- سقف نرخ دارد (در حدود چند صد درخواست در ساعت)؛ ابزار با رسیدن مصرف به ۷۵٪ متوقف می‌شود.

## قدم‌ها (یک بار، توسط صاحب حساب)
1. حساب حرفه‌ای اینستاگرام باید به یک **صفحهٔ فیسبوک** وصل باشد (Instagram → Settings → Accounts Center / Linked accounts).
2. در developers.facebook.com یک اپ از نوع **Business** بسازید و محصول **Instagram (API setup with Facebook Login)** را اضافه کنید.
3. با Graph API Explorer برای همان اپ توکن کاربر بگیرید با مجوزهای:
   `instagram_basic`، `pages_show_list`، `pages_read_engagement`، `business_management`.
   چون حساب و اپ مال خودتان است، App Review لازم نیست.
4. توکن را به توکن **بلندمدت** (حدود ۶۰ روز) تبدیل کنید (Access Token Debugger → Extend).
5. در تنظیمات محیط ابری (منوی محیط در نوار عنوان سشن → Edit) متغیر محیطی بسازید:
   - `IG_ACCESS_TOKEN` = توکن
   - (اختیاری، بعداً) `IG_USER_ID` = شناسهٔ حساب حرفه‌ای که `discover.py whoami` چاپ می‌کند
6. یک **سشن جدید** باز کنید (متغیرها در سشن جدید بارگذاری می‌شوند).

**توکن را هرگز در چت یا فایل‌های مخزن نگذارید** (مخزن عمومی است).

## ادامه در سشن بعد
```sh
cd instagram-index
python3 -I tools/discover.py whoami
IG_USER_ID=<id> python3 -I tools/discover.py run runs/api-step1 20 5 $(head -3 pilot/sample-10.txt)
```
