# گزارش پایلوت

## توافق‌ها (۲۰۲۶-۱۰-۰۶)
- کاربرد: اینستاگرام به‌عنوان منبع «لید اطلاعات»؛ برای هر صفحه: چیست، محتوا، کاربرد، ارجاع بیرونی، نوع (محصول/دانش/واقعی/مجازی…).
- بدون ورود به حساب شخصی؛ صفحه‌های خصوصی فقط علامت می‌خورند و رد می‌شوند.
- آزمون قدم‌به‌قدم برای کشف محدودیت‌ها؛ هر قدم بعد از تأیید.
- همه‌چیز در فضای ابری؛ ذخیره در این مخزن (عمومی‌بودن آن با تأیید صاحب مخزن).

- ورودی: ۹۵۰۵ نام یکتا، بدون تکراری/نامعتبر؛ تاریخ دنبال‌کردن ۲۰۱۸-۱۰-۱۰ تا ۲۰۲۶-۰۹-۲۸.
- Chromium (headless) در کانتینر ابری موجود و آزموده شد.
- دسترسی شبکه به `www.instagram.com` پس از تغییر تنظیمات محیط باز شد (۲۰۲۶-۱۰-۰۶).

## تصمیم: فقط پروفایل، از طریق Apify (۲۰۲۶-۱۰-۰۶)
- پست‌ها فعلاً کنار گذاشته شد؛ تمرکز روی پروفایل.
- مسیر: API شخص ثالث Apify. پایلوت ۱۰ حساب با ابزار رسمی (`apify/instagram-profile-scraper`) و یک ابزار ارزان‌تر برای مقایسه.
- برآورد کل ۹۵۰۵ پروفایل: ۷ تا ۱۰ دلار با ابزارهای ارزان (در اعتبار رایگان، طی حدود ۲ ماه) یا حدود ۱۵ دلار با ابزار رسمی در پلن Starter (یک ماه)؛ +۱۰ تا ۲۰٪ حاشیه. قیمت‌ها باید در داشبورد Apify تأیید شود.
- راه‌اندازی: API credential روی `api.apify.com` (هدر `Authorization: Bearer`)، یا در نبود آن، متغیر `APIFY_TOKEN`. منتظر راه‌اندازی.

## پایلوت Apify (۲۰۲۶-۱۰-۰۶)
- API credential روی `api.apify.com` کار کرد (پلن FREE، سقف ۵ دلار در ماه).
- قیمت تأییدشده از API: ابزار رسمی ۰٫۰۰۲۶ دلار/پروفایل در پلن رایگان؛ `dami_studio` ۰٫۰۰۰۷ دلار/پروفایل + ۰٫۰۰۱ دلار هر اجرا.
- هر دو ابزار ۱۰ از ۱۰ پروفایل را برگرداندند با داده‌های یکسان. هزینه: ۰٫۰۲۶ و ۰٫۰۰۵۹ دلار.
- مقایسه با پایلوت جست‌وجو: جست‌وجو برای `twtbaz` برداشت اشتباه داد (کانال تلگرام هم‌نام)؛ داده واقعی: صفحهٔ متن/بریده کتاب/فلسفه. `navaz1326` و `justin.tries.it` که ناشناخته بودند، اینجا کامل‌اند.
- گزارش: `runs/apify-pilot-10-dami_studio/report.md`. ابزار: `tools/apify_profiles.py` (قابل ادامه، با سقف هزینه برای هر اجرا).
- برآورد کل ۹۵۰۵ حساب با `dami_studio`: حدود ۶٫۷ دلار + هزینهٔ اجراها؛ با اعتبار رایگان ۵ دلار در ماه حدود ۷۰۰۰ پروفایل در ماه.
