# مدل دانش و رادار ابزار

نگارش: ۲۰۲۶-۱۱-۰۵

یک مدل واحد که پیج‌های دنبال‌شده، ذخیره‌های اینستاگرام، منابع (ابزار، ریپو، مدل، مقاله)، ویکی یادگیری، ادعاها، سری‌ها و پروژه‌ها را به هم وصل می‌کند. کاربرد اول: **رادار ابزار برای پروژه‌های کاری**.

## فایل‌ها
| مسیر | چیست |
|---|---|
| `ontology.yaml` | هستی‌شناسی: موجودیت‌ها، رابطه‌ها، مقدارهای مجاز، قواعد (شاهد، فیلدهای فقط-صاحب، حریم خصوصی) |
| `kg.sqlite` | پایگاه‌داده؛ با `tools/build_db.py` از همهٔ منبع‌ها دوباره ساخته می‌شود |
| `data/resources.jsonl` | فهرست یکپارچهٔ منابع با لایسنس، آخرین commit، دفعات اشاره، دسته و ring |
| `data/radar.json` | خروجی فشرده برای داشبورد وب |
| `data/rules_mentions.tsv` | منابعی که مستقیم از لینک‌ها پیدا شده‌اند |
| `data/llm/` | ورودی، دستورالعمل (`BRIEF.md`) و خروجی استخراج با مدل زبانی |
| `data/repos.tsv` | وضعیت ریپوها از راه git ناشناس: وجود، شاخهٔ اصلی، آخرین commit، لایسنس |
| `data/video/` | لایهٔ ویدیو: متن گفتار، متن روی صفحه، خلاصه، نکته‌ها، ارجاع‌ها (نمونه: `0100.json`) |
| `data/radar_owner.tsv` | فقط صاحب: ring، وضعیت بررسی و یادداشت هر منبع |
| `data/projects.tsv`، `project_links.tsv` | فقط صاحب: پروژه‌ها و منابع و مفهوم‌هایی که لازم دارند |
| `data/entity_links.tsv` | هویت وب موجودیت‌های شناخته‌شده: شناسهٔ ویکی‌داده، سایت رسمی، ویکی‌پدیای انگلیسی و فارسی، روش تطبیق |
| `data/entity_curated.tsv` | فهرست بررسی‌شده با دست: عنوان ویکی‌پدیا یا سایت رسمی برای ابزارها و مفهوم‌های پرتکرار؛ `none` یعنی پیوند نخورد |
| `data/dashboard/` | داده‌های صفحهٔ رادار (گره‌ها، یال‌ها، ذخیره‌ها، حساب‌ها، هستی‌شناسی) |
| `dashboard/index.html` | صفحهٔ رادار؛ همین فایل در داشبورد claude.ai و در سایت ایستای `site/` اجرا می‌شود |

## پرسیدن از رادار
```sh
python3 -I knowledge/tools/radar.py find rag          # منابع و پست‌های مرتبط
python3 -I knowledge/tools/radar.py top --category coding-agents
python3 -I knowledge/tools/radar.py resource Graphify
python3 -I knowledge/tools/radar.py item 0100
python3 -I knowledge/tools/radar.py account gittrend.io   # پست‌های یک حساب و منابعی که معرفی کرده
python3 -I knowledge/tools/radar.py licenses
```
در Claude Code و همین گفت‌وگو، skill `tool-radar` همین ابزار را به کار می‌برد.

## Ring (فقط صاحب)
`assess` پیش‌فرض همه‌چیز است. `trial` یعنی روی یک پروژهٔ واقعی با احتیاط، `adopt` یعنی انتخاب پیش‌فرض بعد از تجربهٔ خودم، `hold` یعنی کار تازه با آن شروع نشود. سیستم این را حدس نمی‌زند.

## خط لولهٔ به‌روزرسانی
۱. لینک‌ها: `extract_rules.py` ← `repo_meta.py`
۲. استخراج با مدل زبانی: `prepare_llm.py` ← دستورالعمل `data/llm/BRIEF.md` ← `check_llm.py`
۳. ویدیو: `setup_env.sh` ← `video_pipeline.py fetch` (Apify) ← `video_pipeline.py prepare` (Whisper محلی + فریم‌ها) ← خواندن و ثبت توسط Claude
۴. هویت وب: `link_entities.py` (ویکی‌داده از راه SPARQL؛ API ویکی‌پدیا از IPهای ابری محدود است)
۵. `build_db.py` ← `export_dashboard.py` ← `build_site.py`

## پیوند به موجودیت‌های شناخته‌شده
هر منبع یا مفهومی که موجودیت شناخته‌شده است، به سایت رسمی، صفحهٔ ویکی‌پدیا (فارسی و انگلیسی) و شناسهٔ ویکی‌داده‌اش وصل می‌شود. اگر پست لینکی نداشته باشد، `url` منبع همان سایت رسمی می‌شود.

تطبیق سخت‌گیرانه است، چون پیوند غلط از نبودِ پیوند بدتر است. سه روش دارد و روش هر پیوند ثبت می‌شود:
- `curated`: بررسی‌شده با دست در `entity_curated.tsv`.
- `repo`: آیتم ویکی‌داده‌ای که ریپوی کد آن (P1324) همین ریپو است.
- `title`: عنوان دقیق ویکی‌پدیا، به شرطی که صفحهٔ ابهام‌زدایی نباشد و توضیح ویکی‌داده با نوع منبع جور باشد.

نتیجهٔ ۲۰۲۶-۱۱-۰۵: ۲۲۴ منبع سایت رسمی دارند و ۲۰۵ منبع شناسهٔ ویکی‌داده. ۶۱ گره از ۷۹ گرهٔ ویکی هم به مقالهٔ ویکی‌پدیای خود وصل شده‌اند.

## حساب‌ها
هر پست سازنده‌اش را دارد (`POSTED`). در گراف، ۴۶۵ حسابی که دربارهٔ منابع رادار پست گذاشته‌اند گرهٔ جدا هستند. هر حساب به منابعی وصل است که معرفی کرده، و وزن هر یال تعداد پست‌هاست. در پنل جزئیات منبع، فهرست «چه کسانی دربارهٔ آن پست گذاشته‌اند» آمده و برای هر حساب، همهٔ پست‌های ذخیره‌شده‌اش.

## محدودیت‌ها
- ستاره‌های گیت‌هاب جمع نمی‌شوند (دسترسی فقط از راه git ناشناس)؛ فعال‌بودن از تاریخ آخرین commit دیده می‌شود.
- حدود نیمی از ذخیره‌ها کم‌اطلاع‌اند: ۵۰۵ بدون کپشن و ۴۴۱ فقط «کامنت بگذار / لینک در بیو».
- ویدیو فقط از راه Apify در دسترس است؛ ورود به اینستاگرام و yt-dlp ناشناس از این محیط مسدود است.
- فایل‌های ویدیو و فریم‌ها در مخزن نگه داشته نمی‌شوند.
